# 要件定義書 — タスク管理アプリ

| 項目 | 内容 |
|---|---|
| 文書の位置づけ | 要求定義を「システムとして何を作るか」に落とし込む。要求との対応を明示する |
| 上位文書 | [01_要求定義.md](./01_要求定義.md) |

## 1. 機能要件

| # | 機能 | 内容 | 対応要求 |
|---|---|---|---|
| F-1 | タスク一覧表示 | 全タスクを登録順に一覧表示する。完了/未完了が視覚的に区別できる。残件数を表示する | R-2 |
| F-2 | タスク登録 | タイトル(必須・100文字以内)と説明(任意・500文字以内)で登録できる | R-1 |
| F-3 | 完了状態の切り替え | 一覧上の操作で完了⇔未完了を切り替えられる | R-2 |
| F-4 | タスク削除 | 一覧上の操作でタスクを削除できる | R-3 |
| F-5 | 優先度 | タスクに優先度(高・中・低)を設定できる。登録時に指定でき(未指定は中)、一覧に表示する。一覧を優先度順(高→中→低、同じ優先度は登録順)に並べ替えられる | R-5 |
| F-6 | 期限 | タスクに期限(日付)を任意で設定できる(期限なしも可)。一覧に表示する。期限切れ(期限が今日より前かつ未完了)のタスクを強調表示する | R-6 |
| F-7 | 完了日時 | タスクを完了にした日時を記録し、完了済みタスクの一覧に表示する。完了を取り消すと完了日時は消える。日時はシステムが記録し、利用者は入力しない | R-2 |
| F-8 | カテゴリ | タスクにカテゴリを任意で1つ設定できる(カテゴリなしも可)。一覧に表示する。一覧をカテゴリで絞り込める(「すべて」または1つのカテゴリ)。カテゴリ自体を追加・削除できる。使用中のカテゴリも削除でき、そのカテゴリのタスクはカテゴリなしに戻る | R-7 |

### 入力チェック

| 対象 | ルール | エラー時の挙動 |
|---|---|---|
| タイトル | 必須、100文字以内 | 登録せずエラーメッセージを表示する |
| 説明 | 500文字以内 | 同上 |
| 優先度 | 高・中・低のいずれか | 登録せずエラーを返す(画面は選択式のため通常は発生しない) |
| 期限 | 任意。日付として正しい値(過去日も可) | 登録せずエラーを返す(画面は日付入力のため通常は発生しない) |
| タスクのカテゴリ | 任意。登録済みのカテゴリのいずれか | 登録せずエラーを返す(画面は選択式のため通常は発生しない) |
| カテゴリ名 | 必須、30文字以内、既存のカテゴリと重複しない(前後の空白は除いて判定) | 登録せずエラーメッセージを表示する |

## 2. 非機能要件

| 分類 | 要件 | 対応要求 |
|---|---|---|
| アクセス | HTTPSでインターネット経由で利用できる | R-4 |
| 対応環境 | PCのモダンブラウザ(Chrome / Edge 最新) | R-4 |
| 性能 | 通常操作のレスポンスは体感で遅延を感じないこと(目安1秒以内)。同時利用は10名程度を想定 | — |
| 可用性 | 業務時間帯に利用できること。計画停止は事前周知でよい(SLAは定めない) | — |
| データ | タスクデータはサーバー再起動後も保持されること | — |

## 3. 制約事項

- 技術スタック・アーキテクチャは研修標準(CLAUDE.md)に従う
- 認証は実装しない(スコープ外)

## 4. 受入基準(抜粋)

- タスクを登録すると一覧の末尾に表示される
- タイトル空で登録するとエラーメッセージが表示され、登録されない
- 完了に切り替えたタスクは取り消し線等で視覚的に区別され、残件数が減る
- 削除したタスクは一覧から消え、再読み込み後も復活しない
- 優先度を選んで登録すると、一覧にその優先度が表示される。選ばずに登録すると「中」になる
- 並び順で「優先度順」を選ぶと、高→中→低の順(同じ優先度は登録順)で表示される
- 期限を入力して登録すると、一覧にその期限が表示される。入力しなくても登録できる
- 期限が今日より前の未完了タスクは強調表示される。期限が今日・未来日のタスク、完了済みのタスクは強調表示されない
- タスクを完了にすると、一覧のそのタスクに完了日時が表示される。完了を取り消すと完了日時は表示されなくなる
- カテゴリを選んで登録すると、一覧にそのカテゴリが表示される。選ばずに登録するとカテゴリなしになる
- 絞り込みでカテゴリを選ぶとそのカテゴリのタスクだけが表示され、「すべて」を選ぶと全タスクが表示される
- 既にある名前のカテゴリを追加しようとするとエラーメッセージが表示され、追加されない
- 使用中のカテゴリを削除すると、そのカテゴリだったタスクはカテゴリなしで表示される(タスク自体は残る)
